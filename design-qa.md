# Control Tower design QA

- Reference: approved matte-navy Control Tower composition supplied by Josh.
- Comparison viewport: 1672 × 941, with the approved reference and live Josh 2.0 kiosk rendered side by side.
- Final visual balance: 44% Live Work Board / 56% FinOps in the left column; Today's Jobs retains the full right rail.
- Live Work Board: four full-width agent rows, no model ladder, compact single-line objective readout, and color only from verified active model routes.
- FinOps: exact canonical lanes Codex, Antigravity, Ollama, and Grok; cards and ledger rows highlight only while the same verified route is active.
- Today's Jobs: native current-day schedules only, automatic source discovery, chronological table, semantic complete/skipped/broken/pending states, and no stale historical failure promoted as current.
- Render gate: desktop and mobile semantics pass; zero page overflow, console errors, page errors, failed requests, HTTP errors, private paths, stack traces, or other internal-text leaks.
- Final comparison reviewed: 2026-07-17 America/New_York.
